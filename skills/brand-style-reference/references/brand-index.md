# Brand Reference Index

Use this index to form a shortlist, then read only the selected
`brands/<slug>/DESIGN.md` files.

The following rows are retrieval aids after the brief and direction are understood, not automatic choices by industry. Prefer the approved specimen and original project composition over a familiar brand.

Other peer sources are the main skill's style vocabulary and [composition specimens](presentation-styles/INDEX.md). Choose by requirement fit; presentation-origin examples have no priority for HTML decks, websites or reports.
