# Bold Template Pack

This is a peer reference collection migrated from
`zarazhangrui/beautiful-html-templates`. It sits alongside the other
presentation and brand references under `presentation-styles`; it does not own
the parent workflow and does not define a default, a PPT priority, or a
safe-bold quota.

Every `design.md` and `preview.md` is a sample description. Values and
command-style recipes in those files are examples only; they are not project
defaults, freeze rules, or execution instructions.

## Reading the pack

1. Read `selection-index.json` when metadata is useful for a short list.
2. Read only the relevant `preview.md` files for lightweight visual evidence.
3. Read one `design.md` only when a selected reference needs implementation
   detail.
4. Keep the user's content, the parent direction, and the receiving runtime as
   the authority for any actual deck.

The `deck-stage.js` file is retained here as source material. The executable
runtime is owned by `html-deck-runtime/runtime/deck-stage.js`.
