# Presentation styles reference index

This branch collects visual and narrative reference material that the parent
design workflow may consult when it needs concrete examples:

- `STYLE_PRESETS.md`: legacy preset examples.
- `bold-template-pack/`: 34 migrated template references, each with a compact
  `preview.md` and a detailed `design.md`.
- `animation-patterns.md`: motion examples.
- `html-template.md`: HTML composition examples.
- `narrative-and-artifact-qa.md`: narrative and artifact review examples.

These references are peers with the other style and brand materials. They do
not establish PPT priority, a safe-bold quota, a project default, or a freeze
rule. The html-deck-runtime skill only executes the content, layout, interaction,
and runtime contract passed in by the parent workflow.
