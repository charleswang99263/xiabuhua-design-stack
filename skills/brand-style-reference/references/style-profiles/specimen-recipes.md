# 24 个视觉配方：从图像决策到界面执行

用于选择方向后的精确执行，也可用于方向候选制作。仅读取所选条目。与本目录历史定义并用；这是对“进阶之路”24 张生成图的设计解读与工程转译，不是新的风格史定义，也不是图像模型内部推理。图像不能证明交互或代码质量。

## 如何使用硬性要求

每条包含五层：**识别约束、元素选择、配色角色、排版骨架、执行验收**。识别约束在声称采用该方向时必须成立；具体示例元素与色值不是跨项目的强制预设。用户选定样例后，其主体、色彩角色、字体角色及空间关系成为本项目硬约束，执行者不能自行换成更容易写的图标、卡片或默认组件皮肤。

下面 HEX 是对样例的近似设计重建，不是像素采样；照片/渐变不应被误解为纯色块。按背景→主要文字→主体/辅助→强调解释，不要求每种颜色都使用。真正实施时提取所选图的代表色并校准为项目 token；检查文字与真实背景，不能照抄图内低对比小字。不得把示例色值、字体气质、布局比例称为已经测量的事实。

图中文字多数为装饰标题，且若干方向重复使用宋体、山路和左上标题。这是这组样例的共同主题倾向，**不蒸馏成全部风格规则**。部分标题字形夸张、微文案或刻度不准确，不复制到真实界面。标题、正文、标签、数据与控件必须保留真实 DOM 文本；将需要摄影、绘画、复杂材质的主体单独作为图像资产，不能用低保真 CSS 假装达到同等质量。

## 主视觉语言

### minimal · 极简主义
- **识别约束：**单一视觉重心、少量清晰层级、充足无竞争空间；删减必须提高内容集中度，不能造成任务入口缺失。
- **元素：**样例是一段白色建筑阶梯与采光开口；可替换为一个产品、一件器物或单个排版主体。避免多个无关漂浮物、装饰徽章和卡片堆叠。
- **配色：**暖白 `#F4F0E8` → 墨黑 `#171916` → 石灰 `#CFC8BB`；光影而非多种强调色承担层次。冷白方案同样成立。
- **排版：**样例文字在左侧安静区域，路径向右上延伸；标题与小标签拉开尺度，正文短而稳。标题可用细宋或克制无衬线，不能把细宋当定义。
- **执行验收：**Grid 分配文本与单主体区域，使用真实留白和适当行宽；移动端先读主信息再看主体。普通表单仍保留少量边界和清楚操作。失败：空白很多，但出现多个等权 CTA 或泛用三卡。

### swiss · 瑞士国际主义
- **识别约束：**网格、共同对齐轴、字号/字重级差主导阅读；图形服从信息秩序。
- **元素：**样例 01/02/03、粗斜向红线、无衬线标题；可改为数据、章节或内容序列。装饰不越过文字造成遮挡。
- **配色：**白 `#FAFAF7` → 黑 `#101010` → 信号红 `#F23819`；强调色只承担方向/重点。红可换，黑白与信号层次须保留。
- **排版：**非对称网格，编号与说明共享基线，标题形成第二尺度；不是居中堆叠。窄屏以同一内容顺序收列，不能缩小整张海报。
- **执行验收：**命名 Grid areas、对齐线与角色字号；数字列表、表格和导航继承轴线与字级。失败：只有红黑配色，却使用居中 Hero 与均匀圆角卡片。

### editorial · 杂志编辑
- **识别约束：**标题、导语、正文、图片与图注形成阅读节奏；文字具有编辑角色而非都是营销标语。
- **元素：**主图、辅助裁切、细分隔线、章节/图注；图片提供内容语境。样例山路可换成与主题有关的纪实、产品或人物素材。
- **配色：**纸白 `#F4F0E1` → 深橄榄 `#29301E` → 岩灰 `#979A87` / 景观绿 `#63724C`；主体摄影提供丰富但收敛的颜色。
- **排版：**样例大宋体跨列标题＋侧栏导语＋主摄影；可选择其他版式，但必须有图文主次、阅读行宽和不同密度。正文不直接压在复杂照片上。
- **执行验收：**article/figure/figcaption 与网格对应；表格、引文和长文保留同一字体角色与节奏。失败：大宋体加一张图片，下半页全部回到通用组件模板。

### brutal · 网页粗野
- **识别约束：**直接、暴露式的信息结构与强尺度冲突；内容和链接边界可辨，不靠精饰包裹所有区域。
- **元素：**样例粗黑大字、混凝土阶梯、下划线链接与硬矩形；可换为原始文本、列表或粗粝影像，不必有建筑。
- **配色：**纸白 `#F2F1ED` → 近黑 `#080808` → 水泥灰 `#777973`；该图近单色，粗野也允许其他颜色。
- **排版：**标题挤占主画面，紧密字距与硬切块形成张力；允许视觉突破网格，但交互区域与正文不能被裁掉。
- **执行验收：**裸露列表、明确链接、低装饰容器与强标题比例贯穿正文。失败：以不可读、故障或失去键盘访问冒充粗野；或只是把 Swiss 字体加粗。

### neo · 新粗野主义
- **识别约束：**实色块、明确外轮廓、硬偏移深度与夸张字号构成一致系统；触发/选中状态延续实体感。
- **元素：**样例块状阶梯、单根箭头、少量放射线；替代元素使用同一描边粗细与几何简化，不能混入柔焦玻璃。
- **配色：**奶油 `#FFF5D9` → 黑 `#070707` → 黄 `#FFDC00` / 蓝 `#064CDE` → 粉 `#FF2999`；每一区域主次分明，避免所有颜色均分。
- **排版：**大标题与大型图形直接对抗，方块区域节奏鲜明；正文使用稳健无衬线。标题可短促换行，不能为了模仿固定三行。
- **执行验收：**边框与无模糊 box-shadow 使用共享 tokens；按钮按下缩短阴影、位置变化与真实状态同步，focus 独立可见。失败：仅黑边卡片，标题/元素仍是泛用 SaaS 风。

### maximal · 极繁主义
- **识别约束：**多层、多尺度、多色的丰盛必须围绕可定位的主焦点组织；丰富不等于随机。
- **元素：**样例花卉、横幅、路径、建筑与细节形成景深；可换为主题相关的图像、文字或图案群。重复母题负责收束。
- **配色：**奶油 `#F6E8C4` → 钴蓝 `#173BBA` → 珊瑚 `#F2572D` / 粉 `#F17DB6` / 叶绿 `#669642`；先划主色域，再分配小面积对比。
- **排版：**显著主标题与次级密集片区交替；前中后层有遮挡逻辑，但不能遮挡必读文字或操作。
- **执行验收：**明确 z-index 层级、焦点和阅读出口；高密度表单可用安静的实底区域接住任务。失败：均匀撒装饰、无主次；把全页字号和彩色都提高。

### hand · 手绘插画
- **识别约束：**可辨认且一致的笔触、轮廓与着色方式；图像、标注与装饰像出自同一只手。
- **元素：**样例水彩山径、背包、木路牌和墨线；可换为内容相关的生活物件或说明图。复杂插画需真实资产，不能 emoji 替代。
- **配色：**纸色 `#F5E9CB` → 炭褐 `#40382A` → 鼠尾草 `#85865D` / 暖黄 `#D9B67C`；保留颜料与纸面层次。
- **排版：**插画形成自然引导，手写仅用于标题/短注释，正文保持可读；避免所有组件都画成歪斜边框。
- **执行验收：**统一 stroke、粗细变化和填色质感；状态图标与注释延续笔触。失败：手写字体配通用矢量插画，或正文全部书法化。

### organic · 人文有机
- **识别约束：**自然尺度、柔和非机械轮廓、材料与光线共同表达亲近感；不是给卡片加大圆角。
- **元素：**样例陶土踏石、砂纹、植物影和暖墙；可换木、织物、植物或自然形态的图形，主题决定选材。
- **配色：**砂白 `#EFE3CE` → 深棕 `#604A33` → 陶土 `#B78359` / 橄榄 `#66704B`；保留温度层次而非所有东西米色。
- **排版：**文字与自然曲线相互留让；段落宽度舒适，布局节奏有轻重。字体可人文无衬线或柔和衬线，不锁定具体家族。
- **执行验收：**主体裁切、曲线和触摸区域分开处理，形状柔和但点击目标明确。普通区域保留色温、字体与节奏。失败：无关树叶装饰＋默认白卡。

### geometric · 几何现代
- **识别约束：**有限几何原语的比例、重复、拼接承担表达；结构关系比写实质感更重要。
- **元素：**样例圆、半圆、矩形、三角与路径；项目选定一套原语及组合规则，不能任意增加立体照片。
- **配色：**暖白 `#F4EFDD` → 黑 `#171917` → 红 `#D92220` / 黄 `#F5C321` / 蓝 `#075AA8`；平面色域互相平衡。
- **排版：**文字与几何块组成非对称平衡，留白也是形状；标题可几何无衬线，不需模仿图片中的装饰宋体。
- **执行验收：**SVG viewBox 和 CSS 尺寸保持原语比例，响应式重新组合而不拉伸图形；图标与图表延续形状规则。失败：只使用三原色而没有几何组织。

### deco · 装饰艺术
- **识别约束：**阶梯式几何、轴向秩序、精细线性装饰与主次层级；装饰服务结构。
- **元素：**样例门廊、扇形放射、金线边框；可改阶梯轮廓、折线、几何花饰。不能用欧式卷草随意替换。
- **配色：**祖母绿 `#092E27` → 香槟金 `#D9B86B` → 深绿黑 `#061B17` / 亮金 `#F5D898`；金用于线、边界和少量重点。
- **排版：**样例轴向对称、中央门形焦点、疏朗高挑标题；正文与装饰隔开。可非对称演绎，但需保留阶梯/线性秩序。
- **执行验收：**SVG 线条随显示尺寸保持清晰，装饰密度随视口减少；普通分组与标题继续用同一线性节奏。失败：黑金渐变就称 Art Deco。

### retroweb · 复古互联网
- **识别约束：**特定早期网页/桌面语法可辨识：链接、分栏、窗口与小型图标形成时代线索；需选定一致年代。
- **元素：**样例灰色斜面窗口、蓝色链接、目录、访客计数；演示数据须标示，不伪造真实访问量。不能把所有复古等同像素游戏。
- **配色：**窗口灰 `#C5C5C5` → 黑 `#101010` → 链接蓝 `#0000EE` / 标题蓝 `#1249A4` → 白 `#FFFFFF`；保留功能色角色。
- **排版：**多栏目录与内容窗口、小标题/系统字形；移动端重排目录，不能保留超宽桌面截屏作为页面。
- **执行验收：**真实链接、列表和按钮，边框模拟斜面；保留现代键盘和触摸能力。失败：一张旧电脑照片，实际界面仍普通现代模板。

### y2k · 千禧未来
- **识别约束：**液态/镀铬、半透明、轻盈合成感与未来字形形成一致身份；不是所有科幻都算 Y2K。
- **元素：**样例银色连续曲线、气泡与虹彩高光；替换时保持光滑轮廓和同一反射环境，避免碎裂噪声。
- **配色：**冰白 `#EDF1FF` → 冷银 `#A2AEC7` → 淡紫 `#C3B6E7` / 冰蓝 `#BBD9F2`；小面积虹彩，文字另设足够深的阅读色。
- **排版：**流体主体占主要空间，宽字距/未来标题与曲线相呼应；正文稳定实色，不把铬材质套在所有文字。
- **执行验收：**优先高质量独立资产或可验证 3D，层叠文字保留 DOM；静态 fallback 保留轮廓材质。失败：紫蓝渐变背景＋普通白卡。

### retrofuture · 复古未来
- **识别约束：**过去时代想象未来的造型与印刷语言同时成立；选定时代线索而非现代太空照片。
- **元素：**样例太空时代环形观测站、长曲坡道、巨行星、颗粒印刷；可换时代对应的交通工具/建筑。
- **配色：**旧纸 `#EAD8B3` → 深青 `#31575A` → 锈橙 `#BB7142` / 暗岩 `#5F5446`；有限印刷感色域。
- **排版：**强透视引向远方，旅行招贴式标题与留白；年代字体只在展示角色使用，正文不牺牲阅读。
- **执行验收：**时代线索写入资产 brief，统一颗粒与色调；信息面用印刷分区与细标注继承身份。失败：普通宇宙图加 vintage 滤镜。

### cyber · 赛博朋克
- **识别约束：**密集技术城市/信息环境、深色空间与发光信号的冲突；不能只靠霓虹颜色。
- **元素：**样例雨夜阶梯、密集立面、招牌、湿反射；可替换为符合内容的高密度技术环境。避免无意义可读假指标。
- **配色：**蓝黑 `#08131E` → 冷白 `#DBEDF4` → 青 `#5ECFE9` / 品红 `#E846BC`；暗面承托少量明亮信号。
- **排版：**前中后空间或高密度信息区形成压迫/沉浸感；标题与操作放在可读色域，关键内容不叠加故障动画。
- **执行验收：**区分环境光、内容、状态层；正文需稳定实底/遮罩，禁用闪烁承载必读文字。失败：与 Dark Tech 完全同构，仅把光改成粉色。

### pixel · 像素语言
- **识别约束：**一致的离散像素尺度、轮廓台阶与受控色阶；整套资产必须像同一分辨率体系。
- **元素：**样例平台、石阶、门与山谷；可换主题相关场景与图标。不能混合低分辨率精灵和光滑矢量主体。
- **配色：**天空蓝 `#389BD4` → 深蓝 `#205277` → 草绿 `#80A641` / 亮绿 `#C1D66C` / 暖白 `#FFF0BB`；每种材质使用有限阶调。
- **排版：**场景层次和像素标题，正文允许清晰常规字体；中文像素字必须有实际字形，不得依赖不支持中文的字体。
- **执行验收：**像素素材优先整数倍缩放并保留硬边；高清示意图并不自动等于生产像素素材。失败：模糊低清图、任意锯齿或像素字体单独充当整套风格。

### darktech · 黑色科技
- **识别约束：**低噪声暗空间、精确边缘光、少量技术标注与克制层级；与赛博朋克的环境密度明显不同。
- **元素：**样例单个石墨弧体、细轮廓光；可换一个产品、数据结构或场域。不能默认每个科技需求都用此风格。
- **配色：**近黑 `#080C0F` → 冷白 `#EDF3F7` → 石墨 `#343C44` / 冷灰 `#8E9EAC`；强调应局部，不做满屏霓虹。
- **排版：**少量大信息与巨大暗面，数据/标签精确排齐；标题用有控制的字重和字距，不固定细宋。
- **执行验收：**暗面分层可分辨，正文/边界有足够对比；图表数据色与装饰光分开。失败：纯黑背景吞掉层级，或将赛博图减饱和冒充克制。

## 材质、构图与体验方向

### collage · 拼贴
- **识别约束：**不同来源片段经过剪切、遮挡与重新组合产生新关系；必须看得见片段边界与编排意图。
- **元素：**样例撕纸、照片切片、胶带、植物标本、铅笔箭头；每个片段对应内容任务，不是随机贴纸。
- **配色：**纸白 `#EFE4CD` → 炭蓝 `#31414B` → 赭黄 `#B89044` / 旧蓝 `#8EA8BA`；统一色调连接不同来源。
- **排版：**错位与重叠围绕阅读路径，标题拥有完整底面；纸边和素材可以越界，正文与操作不被遮挡。
- **执行验收：**figure 分层、mask/clip-path 与独立真实文字；窄屏减少重叠，保留片段身份。失败：整张图片加纸纹，没有剪贴关系。

### glass · 玻璃拟态
- **识别约束：**可辨认背景穿过前景面，透明度/模糊/边缘共同说明层级；玻璃物体照片本身不等于玻璃 UI。
- **元素：**样例透明阶梯与色彩背景；转成界面时选择有内容的前景平面与可见后景，不用无关玻璃球凑数。
- **配色：**雾白 `#EDF3EE` → 深青阅读色 `#214750` → 湖青 `#83ADB0` / 珊瑚 `#EFB09B`；半透明面取背景色，白字需实际验证。
- **排版：**前后平面有清晰深度排序；不同层不一律同透明度，密集内容可提高不透明度。
- **执行验收：**alpha surface＋backdrop-filter＋edge tokens；改变背景测试字与边缘，提供不透明 fallback。失败：只有渐变或白色投影卡片。

### neumo · 新拟态
- **识别约束：**凸起与凹陷像从同一连续表面塑出，光源方向统一；不能只用柔和投影。
- **元素：**样例一体成型进度路径、圆形节点与凹入启动区；选择真实按钮/输入/状态参与凹凸关系。
- **配色：**珍珠灰 `#E7E8E6` → 石墨 `#505654` → 亮面 `#FAFBF8` / 阴影 `#B8BCBA`；底与控件同色，文字不跟着低对比。
- **排版：**浅浮雕组织界面，层级主要来自尺度/间距/凹凸；避免每个文本容器都凸起。
- **执行验收：**成对明暗阴影，pressed 可转 inset；真实状态还须图标/文字/边界，不能仅靠阴影判断。失败：白卡悬浮于灰底、没有共同表面。

### skeuo · 拟物
- **识别约束：**可识别物件/材料隐喻被转译为界面；被暗示可操作的部分必须有符合预期的行为。
- **元素：**样例皮革手册、纸页、黄铜指南针和页签；选一个主要物件系统，材质、比例与光源一致。
- **配色：**羊皮纸 `#E7D0A5` → 墨棕 `#4A2F18` → 皮革 `#754821` / 黄铜 `#AC8547`；材质层有区别，不给所有表面加同一纹理。
- **排版：**沿物件结构安置内容，如页签导航、纸页正文、仪表读数；真实阅读布局不能被透视扭曲。
- **执行验收：**纹理资产与 DOM 分离，仪表/页签绑定同一真实状态。失败：背景是一张笔记本照片，前景毫无物件语法；或假旋钮不可用。

### bento · 便当盒布局
- **识别约束：**不同尺寸的内容模块组成有主次的整体分组；内容决定占比，不能每块等权。
- **元素：**样例主路径、进度、目录、计时、阅读和下一步；模块必须有不同信息任务。图内数字仅演示。
- **配色：**暖白 `#F4F5EC` → 深蓝 `#15394E` → 薄荷 `#B9D9CA` / 深绿 `#255A51`；面色用于分组，状态色单独定义。
- **排版：**大主模块与小辅助模块，统一间隙与外轮廓；圆角大小可变，固定六格不是定义。
- **执行验收：**语义 DOM 顺序＋grid-template-areas，移动端按任务重要度线性重排。失败：普通等宽三卡或用空白模块填满矩形。

### immersive · 三维沉浸
- **识别约束：**前中后空间、透视、尺度、光源与主体几何自洽；若声称交互沉浸，需真实镜头/空间状态。
- **元素：**样例绕岛阶梯、海面与顶端门廊；替换为有明确探索目的的空间，不堆无关漂浮几何。
- **配色：**暖白 `#EFE0C5` → 岩灰 `#787B70` → 海蓝 `#98AFB7` / 植被绿 `#586044` / 日光金 `#E6B77F`；受同一光照环境约束。
- **排版：**路径引向空间目标，文本置于低干扰区域；场景与操作层分离，界面不能因相机改变失去可读性。
- **执行验收：**明确使用渲染图、视频还是实时 3D；静态图只验空间视觉，交互需另验加载/镜头/恢复与静态替代。失败：贴一张 3D 图就宣称空间交互已实现。

### motion · 动效主导
- **识别约束：**信息意义依赖时间顺序、持续身份或因果变化；运动必须帮助理解，而非仅增加活泼感。
- **元素：**样例弧形箭头与残影表达推进意图，未显示真实运动过程；需补触发、起态、过渡、终态与重播/中断规格。
- **配色：**深蓝 `#12396C` → 暖白 `#F5DFC0` → 橙金 `#F9B35F`；同一主体跨状态保色/保形，状态变化有语义。
- **排版：**按时间组织焦点迁移，预留终态位置；正文阅读区域不持续晃动。构图可以随状态变化，但 DOM 焦点连续。
- **执行验收：**给出项目 duration/easing/stagger 与状态机，实际播放验证顺序和中断；reduced-motion 直接给等义结果。失败：仅截图有速度线、全页同款淡入，或滚动强制夺权。

### regional · 地域文化
- **识别约束：**明确具体文化/语言/工艺来源与当代转译关系，不能把一种中国水墨图概括为全部地域风格。
- **元素：**本例为当代中国水墨演绎：山水层次、书写笔势、纸面与朱砂点景；不视为特定画派或历史真迹。其他地区需另行建立有依据的元素系统。
- **配色：**宣纸 `#EDE2CD` → 墨黑 `#292923` → 淡墨 `#9D9C90` / 朱砂 `#B8573F`；墨色深浅组织空间，小面积印记式强调。
- **排版：**疏密、留白与笔势组织阅读，书法只用于适量展示文字；可借鉴竖排，但真实正文遵守语言与设备可读性。
- **执行验收：**记录选材来源、象征含义与可替换边界；普通表单延续留白/墨阶/线条而不贴满纹样。失败：传统符号拼盘、假字/假印章冒充真实文化内容。

## 将配方变成项目硬合同

在既有 DESIGN.md / style agreement 中记录，不另起一份互相竞争的规范：

1. **目标与来源：**选定风格 id、样例/目标图片、用户选择或继承依据；标注“图中观察”“工程转译”“新任务调整”。
2. **元素清单：**主主体、辅助元素、禁止元素、每个元素的内容职责；明确保真资产来源/生成方案、透明背景或裁切要求、缺失项。复杂图像尚未准备好时标为未验证，不偷偷换成简陋图标。
3. **颜色表：**surface/ink/secondary/accent/state 角色、具体 HEX/alpha、主辅面积关系和光照；数据色、错误色不被装饰色混淆。所选图中不合格的小字对比要修复并说明。
4. **字体表：**展示/正文/注释/UI 的具体可用字体与中文 fallback、weight、line-height、最大行宽；标题大小相对画布与正文的比例。确认实际字体加载后再验收。
5. **构图图解：**主焦点、阅读方向、文本/主体区域、对齐轴、留白、重叠、裁切、层次，映射到 Grid/Flex/SVG/图像/3D；分别给桌面与窄屏重排。不能只交颜色与字号。
6. **材料与状态：**边界、光源、阴影软硬、透明/凹凸、纹理密度；如有运动，记录触发→状态→意义与降级。定义正文、列表、表单如何延续身份。
7. **冻结与弹性：**前述已选关系必须保留；响应式尺寸、文字长度与无障碍修复可调整。改变主体类型、色彩分工、主构图或材料语言属于方向变化，返回主控处理，不由子 Skill 决定。

## 保真验收，不能只验“像某种风格”

按同一目标尺寸并排比较选定图与真实渲染，逐项填写 **匹配 / 偏离 / 未验证** 与具体区域：主体轮廓与素材品质、主次色域、标题/正文角色、焦点与阅读路线、留白/尺度/遮挡、材料/光源、普通页面连续性、动态状态（如适用）。允许项目适配，但每项偏离要有任务或技术理由；不能用换文案、近似色或通过 build 掩盖主体/构图走样。

先纠正主要主体、布局与色域，再微调描边/阴影。证据不足时不填写“通过”；静态截图不能验证运动、输入和语义。没有真实渲染前，只能称“规则已建立”，不能宣称达到图像模型同等执行精度。后续真实项目的偏差用于修订本配方，不能只依据本文件措辞做自我通过测试。
