# Text entrance review across all scenes

The policy is implemented by `TEXT_ENTRY_POLICY` and component-specific handlers in the museum. This is an illustrative workbench policy, not a universal style rule. Adjust modes/intensity inside the selected project direction. Existing motion is retained where a second text controller would compete.

| Scene | Current text treatment | Reason / boundary |
| --- | --- | --- |
| Kinetic Title Engine | Retain existing three-beat reveal | Text sequence is the mechanism itself |
| Quote Theater | Word entry on quote switch; context immediate | Preserve real quote/context and avoid repeated glyph noise |
| Code Spotlight | Optional decode/words/fade/none; title quiet fade in decode mode | Requested Matrix-like character decoding without executing or corrupting code |
| Shared Element Detail | Retain card continuity; no added text entrance | Keep the same object's identity |
| Sticker Peel | Text moves with one clipped paper surface | Never animate a detached fold or scramble note text |
| Animated Text Disclosure | Measured-height reveal; original text immediate | Avoid competing height and typing timers |
| Text Entry Studio | Six selectable bounded modes and skip | Compare the same actual short sentence |
| Metric Pulse Card | Exact labels and values immediate | Animation must not manufacture changing quantities |
| Sankey Story Strip | Exact labels/values immediate | Preserve conservation and scale interpretation |
| Radar Capability Compass | Exact labels/values immediate | No moving text suggesting changed scores |
| Risk Heat Tile | Exact labels/unknowns immediate | Uncertainty stays explicit |
| 3D Token Field | Quiet heading entrance; node labels immediate | Space carries the interaction |
| Generative Particle Thesis | Quiet heading entrance; signal count immediate | Art movement is separate from real count |
| Physics Priority Map | Quiet heading entrance; item labels/capacity immediate | No fake business ranking |
| Narrative Timeline Rail | Short heading words; retain existing detail transition | Dates and stage facts remain immediately readable |
| Sticky Step Reveal | Retain existing step-driven content transition | No duplicate time controller |
| Spring Stepper Progress | Labels/completion immediate; progress visual only | Navigation and validated completion remain separate |
| Scroll Stack | Readable static card text within moving stack | Local spatial continuity is enough |
| Morphing Flow Path | Quiet heading; state/error text immediate | Visual transition does not prove success |
| Spatial Route Map | Quiet heading; selected relation text immediate | Selection should not wait for letters |
| Decision Stack | No extra text animation | Ordering already shows the decision |
| Before After Scanner | No extra text animation | Keep both versions comparable while dragging |
| Tension Matrix | Values/verdict immediate | Preserve threshold semantics |
| List Reorder | Text follows the real dragged/reordered object | No fresh entrance on every pointer move |
| Interaction Prompt Board | Short heading words; chosen result immediate | Choice feedback remains direct |
| Live Poll Simulator | Vote/count/percentage immediate | No decorative count progression |
| Pixel Transition | Retain existing full-content transition | Pixel mask already explains the change |
| State Button | Status and result immediate | Async state is never delayed by typography |
| Staggered Bulk Selection | Text/count/checkbox immediate; decorative marks stagger | Group state is independent of appearance timing |

For every entrance: retain true text in accessible DOM, hide scrambled visual overlays from accessibility APIs, reserve original layout, handle graphemes, cancel old content on rapid switching, provide skip/reduced/static final states, pause offscreen/hidden work and dispose schedules. Avoid applying these effects to large paragraphs, labels users must act on immediately, or changing data values. Numeric parameters in the lab are tunable example values.
