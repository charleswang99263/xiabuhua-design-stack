XIABUHUA 5.0 / GRAPHICS RUNTIME CONTRACT

图形运行时实验室

三个局部 renderer：D3 负责数据语义，Three.js 负责空间关系，p5.js 负责可控生成过程。每个 specimen 都接受 mount / update / resize / pause / resume / dispose，并保留 HTML 可读结论。

离线优先。 浏览器从本地 vendor 载入依赖；WebGL、依赖加载或 JS 异常时显示明确降级状态。p5 的 seed 与时间来自适配器，不能把随机首帧当作可复核结论。加载边界： 本页是三运行时对比实验室，会一次加载 D3、Three.js、p5.js；业务消费页应按解释任务按需、懒加载单个 renderer，并复用相应 fallback。
01 / DATA SEMANTICS

D3 数据更新

稳定 id 的 keyed join、刻度和逐项可读摘要。

适用：坐标、单位、筛选和可读数值。数据值不藏在 Canvas 里。
02 / SPATIAL STRUCTURE

Three 空间场

真实 Scene / Camera / Mesh；每个 GPU 资源有明确 owner。

适用：深度、连接和空间状态。禁用 WebGL 时明确标记 2D fallback。
03 / GENERATIVE PROCESS

p5 生成过程

显式 seed、注入时钟、按需 redraw；可复核的粒子过程。

适用：生成艺术、粒子实验和可控模拟。reduced motion 保留静态首帧。
验证提示： 反复点击“卸载并重挂载”可观察 canvas / listener / RAF 是否增长；ResizeObserver 会跟随卡片尺寸，hidden/offscreen 时暂停。
