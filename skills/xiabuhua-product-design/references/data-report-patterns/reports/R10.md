## 原有窄屏构造

fixed-width source sheet uses @media(max-width:640px) body padding and JS sheet.style.zoom=Math.min(1,avail/W)

## 可选移动端适配

local proposal only: preserve R10 module order, then stack required slots and collapse optional slots below evidence; do not claim source behavior

## 选择与排除

Select R10 only when its ordered module sequence and evidence forms fit; do not mix report skeletons

## 交互与可读替代

静态阅读优先；需要筛选时提供可复制表格与键盘路径

## 验收

结论、证据、限制、来源和动作均有固定槽位；窄屏/离线边界可验收

## 执行顺序

验证输入与单位 → 按编码计算图形/槽位 → 继承主控已定视觉规则 → 接入真实输入与降级 → 对账、渲染和导出验证。没有有效数据不得补造样本。无生产源码时按本规范实现，不把规范本身称为已运行组件。

## 素材与分发边界

选用第三方代码、字体、图片、地图和媒体时核验适用许可证与分发条件，并保留必要声明。范式规范不授予第三方资产的使用权；未核验资产不可默认打包。
