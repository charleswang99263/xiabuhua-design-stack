# 研究简报卡 / Research Brief Card

类型：范式执行规范。实际实现与验收状态由项目记录；图示、状态模型和生产组件分别计数。

## 成熟度与本地证据

```json
{
  "maturity": "execution-spec",
  "implementation_claim": "完整范式规范；未声明同构生产组件已实现",
  "actual_local_evidence": "html-ppt-component-museum/assets/data-design-lab.html 提供通用示例；本条目精确实现需按合同执行并验收",
  "runtime_required": "HTML/CSS/SVG draft only; unrun",
  "fallback": "静态图与同源表格；地理/动态/查询能力缺失时明确标记，不能替代原能力"
}
```

## 使用任务

研究简报、金融快报、社媒卡片

## 逐记录单位

一页报告中的独立主张、图槽及证据模块

## 数据形状

报告主张→证据形式→限制→行动的整页叙事骨架

## 视觉编码

版心/章节顺序→阅读任务；图表槽位→审阅证据

## 尺度与单位示例

source report catalog viewport=600×1000; density=定尺; source slot topology=hero stat + chart-wrap trend + 4 signals + takeaway

## 布局、字体、线条与配色角色

版心 600×1000；密度 定尺；色系仅作来源参考 Mono；定尺 hero + 平均未使用天数 + 四阻力信号 + 趋势 + takeaway

## 实际输出

原创报告版式结构规格；不复制 source template

## 原有窄屏构造

fixed 600×1000 source stage; @media(max-width:640px) removes body padding; stage remains fixed

## 可选移动端适配

local proposal only: preserve R11 module order, then stack required slots and collapse optional slots below evidence; do not claim source behavior

## 选择与排除

Select R11 only when its ordered module sequence and evidence forms fit; do not mix report skeletons

## 交互与可读替代

静态阅读优先；需要筛选时提供可复制表格与键盘路径

## 验收

结论、证据、限制、来源和动作均有固定槽位；窄屏/离线边界可验收

## 执行顺序

验证输入与单位 → 按编码计算图形/槽位 → 继承主控已定视觉规则 → 接入真实输入与降级 → 对账、渲染和导出验证。没有有效数据不得补造样本。无生产源码时按本规范实现，不把规范本身称为已运行组件。

## 素材与分发边界

选用第三方代码、字体、图片、地图和媒体时核验适用许可证与分发条件，并保留必要声明。范式规范不授予第三方资产的使用权；未核验资产不可默认打包。
