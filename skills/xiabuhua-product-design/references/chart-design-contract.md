# Xiabuhua 数据图与技术图契约

版本：5.0.0  
适用：独立 HTML、报告图表、产品说明和技术图的选型、实现与验收。

## 先写数据，再选图

每张图只回答一个可复核的问题。开始前记录：

| 字段 | 必填内容 |
| --- | --- |
| grain | 每行代表什么实体或时间窗口 |
| measure | 数值、单位、精度、是否允许负值 |
| denominator | 百分比或率的分母；没有分母就不能显示百分比 |
| time | 时区、间隔、聚合窗口、不规则采样和断点 |
| missing | `null`、未采集、不可用、零值的区别 |
| aggregation | sum、mean、median、count 或原始点；不得静默混用 |
| conclusion | 本图要支持的一个判断，以及不能支持的判断 |
| source | 数据来源、快照时间和审阅状态 |

数据形状决定候选，视觉风格只决定材料、字型和标注气质。

## 形状 → 任务 → 候选

| 数据形状 / 任务 | 首选 | 需要说明的语义与拒绝条件 |
| --- | --- | --- |
| 少量分类比较、排名 | 水平条形或点图 | 条形比较保留零基线、单位、排序、并列；点图按任务选择合适范围，不强制从零开始 |
| 连续时间趋势 | 折线、小多图 | 时间间距、聚合窗口、断点；缺失点断线，不插值成事实 |
| 分布与不确定性 | 点分布、直方、箱线图 | 样本量、分箱、异常值、区间定义；没有原始样本就拒绝伪造分布 |
| 构成与占比 | 100% 堆叠或分区条 | 明示分母；多选题、未闭合总和不得强行凑 100% |
| 正负增减贡献 | 瀑布或差值对照 | 起点、终点、贡献加总与舍入规则可对账 |
| 两变量关系 | 散点 / 小多图 | 单位、样本数、缺失处理；相关或共同变化不等于因果 |
| 层级、网络关系 | 树、矩阵或网络 | 边方向、权重、重复边和布局含义；无空间度量时不要把距离当数值 |
| 流量和转化 | Sankey / 路径明细 | 带宽等于量；新增、损耗、回流单独标注并守恒 |
| 流程、状态、时序、架构 | 专用技术图 | 节点语义、责任边界、条件、异常出口、方向和同步异步必须可读 |

图数按独立结论决定，不按列数决定。一个结论可以有图和表两种入口，但两者必须来自同一份计算结果。

## 三种读者模式

- **细读**：面向研究和复盘。允许旁注、直接标签、完整数据表和逐记录交互；阅读顺序先结论、再编码、再证据。
- **基础精确**：面向产品和工程协作。优先熟悉剪影、清晰刻度、零基线、单位和可复制表格；动画不承担理解任务。
- **快速判断**：面向周报、监控和入口页。突出排序、异常和当前值，减少装饰；仍保留单位、期间、分母和异常说明。

模式不能改变数据口径或隐藏负值、缺失和异常。只允许改变标签密度、旁注量、交互默认值和版面节奏。

## 视觉编码合同

位置和长度优先于面积、角度和颜色。每个通道只绑定一个可解释字段；为色觉、打印或快速确认而增加标签、纹理或形状属于冗余编码，必须写明用途。连续数值用连续色阶，分类用离散颜色；不要用红绿作为唯一状态信号。

条形图默认从零开始；若必须截断，轴旁明确标识并提供差值表。折线只连接相邻的已观测点，`null` 形成视觉断点。零是观测值，缺失是未知，`unknown` 不参与聚合。负值保持符号和方向，不改成绝对值排名。

直接标签应优先于悬停。标签过长时换行、缩写并提供完整表格；不要用省略号掩盖实体身份。超过画布承载能力时分面或转表，不能靠更小字号解决。

## 交互、降级和导出

每个交互都回答“用户查什么、状态改变什么、没有交互时如何读”。选择、筛选、刷选、展开和固定必须有键盘路径、触摸等价路径、焦点反馈和结果摘要。悬停不能是唯一入口；大规模网络才按需增加 hover/pin/drag，并同时提供静态快照。

图表渲染层和计算层分离，更新不改变实体 id、series identity 或数据口径。`prefers-reduced-motion` 保留结果并跳过非必要动画；隐藏或卸载后停止观察器、计时器和绘制循环。静态模式仍展示结论、图例和数据表。

SVG 导出必须使用当前筛选后的已审阅数据，保留标题、单位、范围、图例和来源边界；导出不依赖临时 tooltip 或动画中间帧。离线页面声明外部依赖边界，缺依赖时给出可读的表格和错误状态。

## 技术图的拓扑与异常

技术图不是关系散点图的替代品。流程图使用过程框、菱形决策和明确的成功/失败出口；状态图区分状态与转换；时序图保留参与者 lifeline、时间方向、同步/异步；架构图按层和责任边界组织。箭头连接节点边缘，方向和标签表达关系类型；同一节点 id 只能定义一次。

发布前检查：

1. 流程、状态、时序和数据流图不得有意外孤立节点、重复 id、悬空箭头或自相交的关键路径；架构图可以保留明确标注的独立外部系统/边界节点，但必须在图例或旁注说明其不参与当前路径。
2. 箭头不穿过节点或容器标题；分支有条件标签，异常有出口，回流明确。
3. 长中文标签换行后仍在节点内，图中关键语义文字默认不小于 12px；确需更小的刻度/脚注必须保证对比度、提供表格或文本替代，导出视口包含全部内容。
4. 数据流的带宽、流程箭头的方向、控制/数据/事件线型含义互不冲突，并提供图例。
5. topology 失败时拒绝渲染“看起来完整”的图，返回具体节点、边或条件错误。

允许的例外必须写在图旁：简化的概念图可以省略实现细节；示意网络可以使用非数据空间布局，但必须声明距离无数值含义；演示 fixture 可以是本地构造数据，但必须标注 demo、来源和限制。

## 验收证据

机器检查数据契约、单位/分母、缺失和负值处理、id/拓扑、可访问表格、SVG XML 和错误 fixture 拒绝。浏览器检查真实渲染下的标签碰撞、窄屏、键盘、静态模式、reduced-motion 和导出。构建通过、容器有尺寸或 HTTP 200 都不能替代这些证据。
