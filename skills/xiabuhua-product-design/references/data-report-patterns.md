# 数据与报告范式

先读取 chart-design-contract.md 确认数据语义，再按任务查索引并只打开选定条目。

- [61 个数据图表规范](data-report-patterns/charts-index.md)：比较、单位图、时间、分布、关系、层级、矩阵、流量、地理与动态序列。不同视觉编码保留独立规范，不把同名近邻压成一种图。
- [12 套报告版式规范](data-report-patterns/reports-index.md)：整页叙事、主侧栏、逐个图槽、来源脚注与窄屏行为。按证据与阅读任务选择，不拼接互相冲突的骨架。

细读、基础精确和快览是读者任务与表达模式，不是全局强制主题。元素、配色、字阶、线条、留白和标注需服从项目已确认方向；数据编码、分母、实体身份、时间连续性不能被换肤覆盖。

规范覆盖与可运行组件分开：61+12表示可查的执行合同；可运行示例以组件目录与该项目的验证记录为准。动态范式不能用静态截图验收。地图必须具备可用地理数据与许可，缺失时显示表格和缺口，不画假地理图。
